# CINEMO (시네모) - OTT 서비스 웹 프로젝트

> **HTML · CSS · Media Queries 기반 반응형 웹사이트 클론 프로젝트**
>
> Figma 디자인을 기반으로 HTML5와 CSS3(Flexbox, Grid, Media Queries)를 활용하여 PC와 모바일 환경에 대응하는 가상의 OTT 서비스 웹사이트를 제작하였습니다.

## 프로젝트 개요

- **프로젝트명**: CINEMO (시네모)
- **개발 기간**: 2026.10.23 ~ 2026.10.29
- **팀명**: 마스터 (7조)
- **참여 인원**: 5명
- **개발 환경**: Visual Studio Code
- **디자인 도구**: Figma
- **협업 도구**: Git, GitHub

## 기술 스택

- **HTML5**: 시맨틱 태그를 활용한 웹페이지 구조 설계
- **CSS3**: Flexbox와 Grid를 활용한 레이아웃 구현
- **Media Queries**: PC 및 모바일 반응형 웹 구현
- **Git / GitHub**: 브랜치 관리 및 팀 협업

## 주요 구현 기능

**1. 메인 페이지 (`index.html`)**

- 히어로 배너 및 영화·시리즈 콘텐츠 레이아웃 구현
- Flexbox와 가로 스크롤을 활용한 콘텐츠 카드 구성

**2. 마이페이지 (`mypage.html`)**

- 사용자 프로필 및 계정 설정 화면 구현
- 체크박스를 활용한 찜한 콘텐츠 선택 UI 구성
- CSS Grid 기반의 반응형 콘텐츠 목록 구현

**3. 프로필 선택 페이지 (`profile.html`)**

- 사용자 프로필 선택 및 관리 화면 구현
- 프로필 클릭 시 메인 페이지로 이동
- CSS Grid를 활용한 반응형 프로필 배치

## 반응형 웹 구현

- **PC (769px 이상)**: 프로필 및 찜한 콘텐츠 4열 배치
- **모바일 (768px 이하)**: 프로필 및 찜한 콘텐츠 2열 배치
- 화면 크기에 따라 이미지, 여백 및 콘텐츠 레이아웃 조정
- CSS `:root` 변수를 활용한 공통 디자인 시스템 관리

## 프로젝트 폴더 구조 및 실행 방법

```text
CINEMO/
├── index.html        # 메인 페이지
├── mypage.html       # 마이페이지
├── profile.html      # 프로필 선택 페이지
├── styles/
│   ├── reset.css     # 기본 스타일 초기화
│   ├── common.css    # 공통 스타일 및 CSS 변수
│   ├── style.css     # 메인 페이지 스타일
│   ├── mypage.css    # 마이페이지 스타일
│   └── profile.css   # 프로필 페이지 스타일
└── asset/            # 이미지 및 SVG 파일
```

**실행 방법**

1. GitHub 저장소에서 프로젝트 파일을 다운로드하거나 Clone합니다.
2. 프로젝트 폴더에서 `index.html`을 브라우저로 실행합니다.
3. 브라우저 개발자 도구에서 PC 및 모바일 반응형 화면을 확인합니다.
